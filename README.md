# 263AT — Automated Trading of individual stocks

個別株の自動売買システム、およびその**売買コードをClaudeに定期生成させるための仕組み**を構築するプロジェクト。

## プロジェクトの本質

263ATが作るのは「売買システム」そのものではなく、**「売買システムを生成・検証・更新するシステム」**である。

```
        [ 263AT = メタシステム ]
                  |
   数か月ごとに ↓ 生成 / 更新
                  |
        [ 売買システム v_n ]  ← 機械的に(一部LLM)売買を実行
                  |
   実績 ↓ フィードバック
                  |
        [ 263AT が生成方法を改善 ]
```

したがって成果物は 2 層ある。

| 層 | 何を作るか | 成功の測り方 |
|---|---|---|
| L1: 売買システム | 買いスコア / 売りスコア / ポジションサイジング | 実現損益、期待値 |
| L2: 生成メタシステム | ルール、パラメータカタログ、検証プロトコル、Claudeへの指示体系 | **生成した売買システムの、生成後（真の未来）での成績分布** |

L2の成績は「1本の売買システムが勝ったか」ではなく、**「生成される売買システム群の期待値が正か、そして世代を追って改善しているか」**で測る。

## 最優先事項

**トレードの最終的な＋利益。** それ以外（美しい設計、高いシャープレシオ、学術的正しさ）はすべて手段。

## 確定している前提

| 項目 | 内容 |
|---|---|
| 対象市場 | 日本株 + 米国株（両方を最初から） |
| 想定保有期間 | 半年〜5年。ただし**保有期間自体を最適化対象パラメータとして扱う** |
| 個別株への配分 | 〜300万円（全体ポートフォリオの約10%。残り90%は投資信託） |
| リスク選好 | **期待値重視**。勝率は低くてよい。10銘柄中1銘柄の大勝ちが他の損失を覆う非対称ペイオフを狙う |
| 調整可能性 | リスク/リターン選好を1〜2個のパラメータで連続的に変更できる設計にする |
| コード更新頻度 | 数か月ごとにClaudeが売買コードを再生成・更新 |
| 運用形態 | 生成期間の間はそのコードで機械的に売買（一部LLM判断を含みうる） |

## 開発フェーズ

1. **調査** — 使えるパラメータ・法則・数式を洗い出す ← *現在ここ*
2. **データ基盤** — 日米の株価/財務/需給/開示データを、ルックアヘッドバイアスなく再現可能に取得
3. **検証環境** — 過去データで「売買システムを生成 → その後の期間で評価」を回せるハーネス
4. **生成方法の改善** — 生成プロトコルを世代交代させ、生成後成績の分布を改善する
5. **ペーパートレード** — 実データ・実時間で無資金運用
6. **実弾投入** — 段階的に資金を入れる

## 調査の方針（エビデンス階層）

個別株投資には長い歴史があり、知見も「知見に見えるマーケティング」も大量にある。
本プロジェクトは情報源を4階層に分け、**T4（ブログ・投資メディア・商品説明・書籍の要約記事）は採用しない。**

| 階層 | 情報源 | 扱い |
|---|---|---|
| T1 | 査読付きトップジャーナル + 独立再現あり、または大規模再現DB（Open Source Asset Pricing 等）に収録 | ★★★の候補 |
| T2 | 査読付き掲載だが独立再現が未確認 | ★★ |
| T3 | ワーキングペーパー、手法とデータを開示した運用会社のリサーチ | ★（自前検証必須） |
| T4 | ブログ、投資メディア、商品説明、「年利X%」系 | **採用しない** |

参考文献は原則として一次文献（原論文の PDF / SSRN / NBER / 学会誌）にリンクする。
詳細は [パラメータカタログ §0](docs/01_parameter_catalog.md) を参照。
