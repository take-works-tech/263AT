## 0. 第1回から学んだこと

第1回で本命だった X04（臨床試験の登録数）は、
「裾に +、平均には符号なし」と予測して**両方とも逆**だった。

外れた理由は明確だった。

> **試験を多く登録できる企業は、そもそも資金力と実績がある。**
> 本数は「当たりくじの枚数」ではなく**企業の体力の代理**だった。

**つまり私は「数を数えたつもりで、規模を測っていた。」**

**この失敗は、規模と相関するものすべてに起こる。**
論文数も試験数も特許数も、**大きい企業ほど多い。**
規模で割らなければ、何を測っても「大企業かどうか」になる。

→ **今回は、水準を一切使わない。** 変化と比率だけを使う。

## 1. なぜ物価を選ぶか

**マージンは、産出価格と投入価格の差で決まる。**
そして両者は**業種ごとに違う品目**で動く。

    鉄を買って自動車を売る会社 → 鉄が上がると利益が減る
    鉄を掘って売る会社         → 鉄が上がると利益が増える

**同じ「鉄鋼 +20%」が、銘柄によって逆向きに効く。**
だから断面のランキングを動かす（マクロ指標そのものは全銘柄で同じ値なので
断面には何も寄与しない — 戦争ニュースや金価格を除外した理由と同じ）。

**そして先行性がある。**
現在の収益性パラメータ（B02 ROA、B06 粗利/総資産）は
**決算が出てから分かる。3ヶ月遅れである。**
物価は**毎月出る。** 決算より 2〜3ヶ月早く、粗利率の方向が分かる。

出所は **BLS 生産者物価指数（PPI）**。
**登録不要・無料**（1回25系列・10年、1日25回）。実測で確認した。

---

## 2. 測るもの（定義を先に固定する）

業種（Fama-French 49）ごとに、**投入品目**と**産出品目**を割り当てる。
割り当ては**業種の定義から決め、データからは決めない。**
（例: `Autos` の投入 = 鉄鋼・樹脂・電子部品、産出 = 自動車）

| ID | 名前 | 定義 |
|---|---|---|
| **Y01** | 投入価格の変化 | 投入品目指数の **12ヶ月変化率** |
| **Y02** | 産出価格の変化 | 産出品目指数の **12ヶ月変化率** |
| **Y03** | マージン圧力 | **Y02 − Y01**（産出の伸び − 投入の伸び） |
| **Y04** | マージン圧力の加速 | Y03(t) − Y03(t−6ヶ月) |

**時点の扱い。** PPI は当月分が**翌月中旬に公表**される。
`t` 時点で使えるのは **t−2ヶ月**までの指数とする（保守側に2ヶ月遅らせる）。
**この遅れを1ヶ月にすれば数字は良くなるはずだが、変えない。**

**水準（指数そのもの）は一切使わない。** §0 の理由による。

## 3. 予測（**これが本体**）

### Y03 マージン圧力 → **+**

**これが本命である。**

産出価格が投入価格より速く上がっている業種は、
**次の決算で粗利率が改善する。** それは決算発表まで価格に織り込まれない。

**根拠**: 決算は3ヶ月遅れで出る。物価は毎月出る。
市場が物価指数を業種ごとに集計して見ていないなら、この情報は残る。

**反論も書く。** アナリストは業種のコスト構造を見ている。
特に大型株では織り込まれている可能性が高い。
→ **小型株でより強い**と予測する（これも検証対象にする）。

### Y01 投入価格の変化 → **−**

投入が上がる＝コストが上がる。単独では負の符号。
ただし**産出に転嫁できる業種では効かない**ので、Y03 より弱いと予測する。

### Y02 産出価格の変化 → **+、ただし Y03 より弱い**

産出が上がるのは良いことだが、**投入も一緒に上がっていれば意味がない。**
インフレ期には両方上がる。だから単独では弱い。

### Y04 マージン圧力の加速 → **+、ただし Y03 より弱い**

変化の変化なので、ノイズが大きい。
**Y03 より弱いと予測する。** 強ければ、それは驚きである。

### 裾（10倍株）への効き → **4本すべて符号なし**

**物価は10倍株を当てない。**
マージン圧力は数四半期のスケールの話で、
**5年で10倍になるかどうかとは無関係**である。

**第1回では裾に期待して外した。今回は期待しない。**

## 4. 測り方（先に決める）

1. **一度だけ測る。** 遅れ（2ヶ月）も窓（12ヶ月・6ヶ月）も変えない
2. 評価は3つ
   - **(a) 上位20%の平均リターン**（250日）
   - **(b) 10倍株の出現率**（5年、**符号なしと予測**）
   - **(c) 時価総額の下位半分だけで測った (a)**（小型でより強いという予測の検証）
3. 既存28本と一緒に縮小推定に入れ、**重みがゼロでないか**を見る
4. **生存者バイアスの警告を併記する**

### 判定の基準

| 結果 | 判定 |
|---|---|
| 予測した符号で、独立 t > 3.0 | **採用** |
| 予測した符号で、独立 t が 2.0〜3.0 | 保留。前向き記録へ |
| 予測した符号だが t < 2.0 | 不採用。**予測は当たったと記録** |
| **予測と逆の符号** | 不採用。**外れたと記録し理由を考える** |
| Y04 が Y03 より強い | **「驚き」として記録する**（予測外） |

**t > 3.0 を下げない。**

## 5. 予想される失敗

- **投入・産出の品目割り当てが最大のリスク。**
  `Autos` に鉄鋼を割り当てるのは妥当だが、`BusSv`（事業サービス）に
  何を割り当てるかは恣意的である。
  → **割り当てられない業種は「作らない」。** 無理に埋めない
- **産業連関表を使っていない。** 本来は投入係数で加重すべきだが、
  BEA の表は登録が必要。**等加重で代用する。**
  これは近似であり、**精度を落としている自覚がある**
- **業種内で一定の値になる。** 同じ業種の全銘柄が同じ Y03 を持つ。
  → **業種内正規化を通すと z=0 になって消える。**
  **業種を跨いだ正規化が必要**で、これは他のパラメータと扱いが違う。
  **この非対称性が結果を歪める可能性がある**
- 生存者バイアスは消えない

**3つ目が特に重い。** 業種内で一定なら、
「業種を選ぶパラメータ」であって「銘柄を選ぶパラメータ」ではない。
**それでも意味があるのは、業種の配分が変わるから**だが、
**現在の実装（業種内正規化）とは噛み合わない。**
→ **噛み合わないことを承知の上で測り、結果を記録する。**
