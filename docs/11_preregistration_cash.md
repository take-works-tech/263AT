# 事前登録（第4回）— 現金 47% を投資に回したら何が起きるか

> **測る前に書く。** 結果を見てから「そう思っていた」と言えないようにする。
> 凍結: `python tools/freeze_prereg.py --doc docs/11_preregistration_cash.md --freeze`

---

## 1. 何が起きているか

`tools/run_system.py` に診断を入れて分かったこと（2026-08-25）。

> **投資比率 中央値 53%**（最小 43% / 最大 64%）
> 社債を含む旧パネルでも、普通株のみの新パネルでも**まったく同じ 53%**

設計上の投資上限は **90%** である。**13.5年を通して、半分近くが現金だった。**

### 原因（`src/sizing.py` の `apply_limits`）

```
kelly_weights   スコア/ボラ を正規化 → 合計 1.00
段1 銘柄上限15%  超えた分を切る      → **減るだけ。配り直さない**
段2 業種上限35%  超えた業種を縮める   → **減るだけ。配り直さない**
段3 投資上限90%  合計が90%を超えたら縮める → **既に90%未満なので一度も効かない**
段4 最小2%未満   落とす              → **減るだけ。配り直さない**
```

**段3 は「上限」であって「目標」ではない。**
段1・2・4 が削った分を戻す処理がどこにも無いので、
**合計は 1.00 から一方的に減っていく。**

`max_names` による切り詰めは 2026-08-24 に配り直すよう直した。
**同じ誤りが4箇所あって、1箇所しか直していなかった。**

---

## 2. 何を変えるか

`apply_limits` を「上限を満たす**最大**の配分」を探すように変える。

```
繰り返す:
    銘柄上限・業種上限を適用（減らす）
    合計が投資上限に満たなければ、**上限に達していない銘柄に配り直す**
    最小ポジション未満を落とす
    変化が無くなったら終わり
```

**上限は一つも緩めない。** 15% / 35% / 90% はそのまま。
**「上限を守りつつ、目標まで投資する」**に変えるだけである。

上限の組み合わせで 90% に届かないことはありうる
（例: 候補が全員同じ業種なら 35% が天井）。**そのときは届かないままでよい。**

## 3. 予測（**結果を見る前に書いている**）

基準（新パネル `gate`、普通株のみ、測定済み）:

```
CAGR +11.91% / 最大DD −15.4% / コスト 36.4% / 投資比率 53% / 保有 18銘柄
3年窓 最悪 +1.4%・マイナス 0/127 ／ 1年窓 最悪 −7.3%・マイナス 18/151
```

### C1 — 投資比率は **85〜90%** になる

候補は45銘柄あり、業種も分散しているので、上限には引っかからないはず。

### C2 — 保有銘柄数は **25〜35** に増える

配り直せば、最小2%を下回っていた銘柄が2%を超えて生き残る。

### C3 — CAGR は **+16% 〜 +21%**

現金が 0% のリターンなので、素朴には 11.91 × (0.88/0.53) ≒ 19.8%。
ただし銘柄数が増えて薄まる分と、コスト増を引くので幅を広く取る。

### C4 — 最大ドローダウンは **−22% 〜 −28%**

−15.4% × (0.88/0.53) ≒ −25.6%。

### C5 — コストは **50% 〜 65%**（元本比）

回転する金額が 1.66 倍になる。

### C6 — **「3年以上の窓でマイナスにならない」は壊れる**

**これが最も重要な予測である。**
3年窓の最悪は現在 +1.4% しかない。1.66 倍の変動を掛ければ届かない。

> **3年窓にマイナスが 1〜25 本（/127）出る。**
> 5年窓は **0/103 のまま保たれる**（こちらは最悪 +5.1% と余裕がある）。

## 4. 採否の規則（**測る前に決める**）

### 4.1 バグは直す。**これは成績で決めない**

現在の 53% は、**誰も選んでいない。** 4箇所の配り直し漏れの結果である。
「現金を半分持つ」という判断があったわけではない。

> **仕様が 90% と書いてあるなら、コードは 90% を目指すべきである。**
> 意図しない現金 47% は、リスク管理ではなく**欠陥**である。

### 4.2 **そのうえで、現金比率を明示的な設定にする**

依頼者の狙いは2つあり、**両立させる必要がある。**

| | 言葉 |
|---|---|
| 攻める理由 | 「投資信託より成果を出さないような個別株の買い方をする必要はない。**ある程度リスクをとる必要がある**」 |
| 守る理由 | 「**ただし、マイナスにならないようにしたい**」 |

だから規則はこうする。

> **C6 が当たって3年窓にマイナスが出たら、`max_invested` を
> 「3年窓が 0/127 を保つ最大の値」に選ぶ。**
>
> **偶然の 53% ではなく、選んだ値にする。**
> 53% が答えなら 53% でよい。**違うのは「選んだかどうか」である。**

探索は `max_invested` を 0.5 / 0.6 / 0.7 / 0.8 / 0.9 で振り、
**3年窓のマイナス本数と CAGR の両方を表にして残す。**

### 4.3 やらないこと

- **上限（15% / 35%）は動かさない。** 一度に2つ変えない
- **最小ポジション 2% も動かさない。** 同じ理由
- 成績が良いほうを後から選ばない。**規則は上に書いた通り**

## 5. 予想される反論と、それへの答え

**「47% の現金は、結果として下落を防いでいたのではないか」**

そうかもしれない。だから 4.2 で**明示的な設定として選び直す。**
消すのではなく、**偶然を選択に変える。**

**「CAGR が上がっても、それは単にレバレッジを掛けただけではないか」**

その通りである。**だから CAGR の上昇そのものは成果ではない。**
見るべきは「同じ投資比率に揃えたときに勝っているか」であって、
それは §4.2 の表で読める。
