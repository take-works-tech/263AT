## 0. 監査で確定した欠陥（修正は測定結果に関係なく採用する）

これらは「成績を良くする変更」ではなく**測定と会計の誤りの訂正**である。
したがって **R-1〜R-4 は、測定でどちらに動いても採用する。**

| ID | 欠陥 | 出典 |
|---|---|---|
| LA-1 | **時価総額が遡及調整後の株価で計算されている。** `mcap = shares × close(調整後)`。未来の分割情報が TOO_SMALL ゲートと A03/A04/A06、L01/L02 の大型ピア選定に漏れる。2015-06 断面で 24% の銘柄が影響（NFLX が $569M の「割安小型株」、SLS が $6.19T の「最大企業」として記録されている） | 監査 LA |
| DIV-1 | **配当が会計から完全に欠落。** 価格は配当未調整、ポートフォリオは配当を現金計上せず、fwd ラベルは価格のみ。ゲート後断面の 45-58% が配当を払い、平均利回り 1.6-2.0% | 監査 DIV |
| DIV-2 | **特別分配・清算分配が「暴落」として記録される。** ELME は 2026-01-08 に $14.67/株の清算分配（データ上 −84%）。**前向き記録第2号が ELME を9位で採用している**（財務は清算前・価格は分配後で割安指標が壊れるため） | 監査 DIV |
| PM-2 | **execute() がアルファベット順の一巡で処理し、売りより先の買いが現金不足で切り詰められる**（165ヶ月中26ヶ月で発生、通知は捨てられていた） | 監査 PM/V |
| V1 | 表示される「投資比率 90%・27銘柄」は**執行前の目標値**で、執行後の実現値は一度も測られていない | 監査 V |
| V3 | 最大DDが**月末値のみ**で計算されている（日次評価は毎日計算して捨てている） | 監査 V |
| V4 | 保有銘柄の価格系列が尽きると**最終値で永久に評価され続ける**（ゾンビ保有）。生存者バイアスをデータ側で直しても、このままでは損失が凍結価値に化ける | 監査 V |
| V6 | 強制売り（ゲート違反等）が min_trade_frac 未満だと**黙って素通りする** | 監査 V |
| EXE-1 | next_open() が**出来高ゼロの幻の価格で約定できる**（halted フラグは yfinance 経路では常に False で、持ち越し保護は死んでいる）。log_return も前日出来高ゼロを見ない | 監査 DIV |
| SPL-1 | 価格キャッシュに**分割誤調整の glitch バーが115本**残っている（fetch_prices.py が verify() を呼んでいない） | 監査 DIV |
| COST-1 | 手数料 5bps は SBI 実費（**0.495%/片道、上限$22**。この口座の玉 ~$775 では上限に届かず **49.5bps**）の1/10 | 監査 COST |
| COST-2 | スプレッド一律 25bps は実際の保有銘柄の実測（Corwin-Schultz 中央値 **片道79bps**、$2未満はティック下限だけで片道44bps以上）の 1/3 | 監査 COST |
| PM-4 | 「分数 Kelly 0.25」は**正規化で約分されて無意味**（実体は score/vol 比例配分 + 投資比率90%）。文書だけが安全性を主張している | 監査 PM |
| STAT-1 | **現行構成のランダム対照が存在しない**（eq_rand.json は社債除去・配り直し修正の前）。スコアの寄与は旧構成でしか測られていない | 監査 STAT |

### 統計監査の結論（数字の読み方の訂正。docs/09 に反映する）

- 「3年窓 0/127」の独立本数は **約4.5本**。全勝でも「真のマイナス確率 ≤49%（95%CL）」までしか言えない。**この数字で投資比率を上げてはいけない**
- 上振れバイアスは2つではなく**3つ**: 生存者・カタログのルックアヘッド・**同一パネル上の構造選択**（売りルール無し・250日保有は旧構成の in-sample で選ばれた）
- λ が格子上端に張り付き実効 4.8本 ⇒ **重み学習層は実質不活性**（符号付き単変量スクリーンと同等）。**再重み付け・パラメータ追加に工数を使わない**
- 2025年以降（OSAP 設計データの外）のスコア対ランダムは **+0.58pp/年、t=0.20**（旧構成）。**スコアのアルファは設計外期間ではまだ何も証明されていない**

## 1. 修正の階段（1段ずつ測る。各段は前段との差だけを見る）

すべて同一パネル・同一乱数・同一期間（2012-01〜2026-07）。

| 段 | 変更（前段に追加） | 種類 |
|---|---|---|
| L0 | 現行コード・現行パネル（再現済み: **CAGR +22.12%** / コスト130.1% / 月末DD −25.4%） | 基準 |
| L1 | 執行修正: 売り先行の二段執行・強制売りの min_trade_frac 迂回・出来高ゼロ約定禁止・実現投資比率の記録・日次DD | 訂正 |
| L2 | **配当を現金計上**（保有銘柄の ex-date で株数×配当） | 訂正 |
| L3 | **パネル再構築**: mcap = 実際の株価×報告時点株数（分割基準を揃える）/ fwd ラベルを配当込みに / **分配殻ゲート**（直近365日の分配合計 > 株価の20% を除外。閾値は掃引しない） / glitch バー除去 | 訂正 |
| L4 | **実コスト**: 手数料 min(0.495%, $22)/片道 + 銘柄別スプレッド max(CS半値, 0.5×tick/価格) + 売りに SEC/TAF 1bp + **現金に短期金利**（年次の3ヶ月TB平均、下記固定表） | 訂正 |
| L5 | **入替ヒステリシス**: 参入 = ランク ≤ N、退出 = ランク > 2N または スコア ≤ 0。**継続保有銘柄は再ターゲットしない**（上限 15%/35% 超過の切り下げのみ）。解放された現金は新規参入に配る | 再設計 |
| L6 | L5 + **新規参入を等加重**（score/vol をやめる。理由: score/vol は同スコアの高ボラ銘柄=裾候補を系統的に排除する。社債事故と同じ機構が普通株の中でまだ動いている。裾を狙う設計の根拠測定は等加重で行われていた） | 再設計 |
| L7 | 勝った方の構成で掃引: 投資上限 {0.90, 0.95} / 最小ポジション {2.0%, 1.5%, 1.25%} / 最低株価 {$1, $2} | 再設計 |
| L8 | 最終構成で: 売りルール再測定 {なし, 損切り−15%, −30%, トレーリング−25%} / **ランダム対照** / 税引後表示 / 転がり窓・日次DD | 検証 |

2020: 0.4% / 2021: 0.05% / 2022: 2.0% / 2023: 5.0% / 2024: 5.2% / 2025: 4.4% / 2026: 4.3%

### 採否の規則（先に決める）

1. **L1〜L4 は測定結果に関係なく採用**（会計の訂正であって最適化ではない）
2. L5 は R-5 の基準を満たしたときだけ採用
3. L6〜L8 は各予測の範囲内なら**構造的理由で**採用（in-sample の CAGR 順位では選ばない）
4. **prior.ADOPTED（31本）と重み推定の方法は一切変更しない**
5. 前向き記録第1号・第2号は変更しない。修正後の構成で**第3号**を追記し、
   以後の記録には**同条件のランダム対照と等加重ユニバースを併記する**
   （ペア差の検定で判定所要が 44年 → 3〜5年に縮む。監査 STAT-7）

## 3. 測らないこと・変えないこと

- パラメータの追加・削除・符号変更（§4.9 で行き止まりと実証済み。監査 STAT-4 も同結論）
- λ の格子・目的関数の変更
- min_trade_frac の再掃引（コストの84%は入替チャーンであり min_trade_frac ではない。監査 PM-5）
- 為替 FX=150 固定は今回直さない（ゲート閾値の歴史的一貫性の問題として docs/09 に限界を記載する）
