## 1. 確かに言えること / 言えないこと

| 主張 | 根拠 | **信頼度** |
|---|---|---|
| **3年以上の窓でマイナスにならなかった** | **0/127**（最悪 +2.9%）／5年 0/103（最悪 +8.2%） | **中〜高。投資比率 0.5〜0.9 のどこでも 0本** |
| **指数（SPY）を上回る** | **+21.8%** 対 +13.7% | **低い。交絡が2つ残る**（下記） |
| **1年では −14.5% を覚悟する** | 1年窓 最悪 −14.5% / マイナス 16/151 | **高い。実測** |
| 指数が下げた年には上回った | 3/3（旧構成での値） | **再測定が要る** |
| 投資比率は 90% | 中央値 90%（全期間） | **高い。実測** |

**「指数を上回る」を信じてはいけない。**
交絡（生存者バイアス・カタログのルックアヘッド）は何も解決していない。
**+8.4% だったときに「勝てない」と書いたのと、証拠の質は同じである。**
変わったのは数字だけで、**証拠は前向き記録を待つしかない。**

「3年窓の最悪 +3.2%、12/12」と書いていたのは**年次の窓 12本**で、
月末ごとに取ると 127本ある（`tools/measure_windows.py`）。

**すべての数字に、除去できない2つの上振れ交絡が残る。**

1. **生存者バイアス** — 2012年の残存率 32.6%。廃止銘柄は最初から入らない
2. **カタログ自体のルックアヘッド** — 2012-2026 は設計にとって全部 in-sample

**この2つを除けるのは前向き記録だけ**（§5）。

## 5.5 前向き記録 第1号について（**修正前のシステムを測っている**）

`data/generations.jsonl` の1件目（asof 2026-05-31）の上位10銘柄には
**ATLCP / AIZN / ATLCL** が入っている。**社債2本と優先株1本**である。

つまり**この記録は、証券種別を直す前のシステムを測る。**

**それでも記録は消さない・直さない。**

- 追記のみ・ハッシュ連鎖なので、直せば `run_tests.py` が落ちる
- そして**直すべきでもない。** 「2026-05-31 の時点で、この構成は
  こう選んだ」という事実は、後から変えてよいものではない
- 2027-02-05 の評価は、**修正前のシステムの成績**として意味を持つ

修正後のシステムの記録は、**新しい基準日で第2号として追記する。**
価格データは 2026-08-21 まであるので、パネルを伸ばせば作れる。

**「記録が古くなったら書き換える」ができる状態なら、記録は証拠にならない。**

## 7. このプロジェクトで繰り返し起きたこと

**8つの「測定を壊す欠陥」のうち6つは、良い成績ではなく
「おかしな数字」から見つかった。**

そして**失敗が成功の顔をして返ってくる**ことが繰り返し起きた。

| | 症状 |
|---|---|
| `min_trade_frac` を上げる | 取引をやめるが「CAGR +0.50%」と表示 |
| `max_names` を下げる | 現金比率が上がるだけだが「集中の効果」に見える |
| `quarter_series` の戻り値 | **自己テストは 17/17 通過**、実データで落ちる |
| `\| head` でパイプを切る | **終了コード 0 で「完了」と報告される** |
| `str.replace` の空振り | **一致しなくてもエラーにならない** |

→ **数字が出たら、まず測り方を疑う。**
→ **「完了」と表示されても、行数を数える。**
