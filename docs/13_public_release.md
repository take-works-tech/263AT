## 1. 除去したもの

| 何を | なぜ |
|---|---|
| `research/oap_signal_doc.csv` | **OSAP (Chen & Zimmermann) の文書テーブルのほぼ丸ごとの複製。** 第三者素材の再配布にあたる |
| `research/oap_*.csv` `oq17/oq24_*.csv` `z12_*.csv` `us_cross_section.csv` | 外部データ（OSAP のリターン系列・SEC XBRL）から計算した派生物。個別の統計値の引用（カタログや `params/_overrides_oap.yaml` の出典付き数値）とは違い、**行単位でデータセットと1対1になるファイル**は置かない |

- ファイルはローカルの `research/` に残っている（`.gitignore` で除外）。分析の入力として使い続ける
- **git 履歴からも `git filter-repo` で完全に除去した**（現在のツリーから消すだけでは、履歴から取り出せてしまう）

## 2. 併せて行ったこと

- **コミットの著者メールを GitHub の noreply アドレスに書き換えた**
  （個人メールが全コミットに入っており、公開すると収集される）
- 全履歴の秘密情報スキャンを実施（検出はスキャナ自身のパターン定義のみ。実物なし）
- `.env` は最初から未追跡。pre-commit の `security_check.py` が全コミットを検査してきた

docs の本文中の SHA は**旧 SHA のまま**である。記録は書き換えない（書き換えられない
ことが証拠性の根拠なので）。対応は以下の通り:
