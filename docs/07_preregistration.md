# 事前登録 — 外部データのパラメータ

> **作成 2026-08-24。まだ一度も測っていない状態で書いている。**
> ここに書いた後で符号や定義を変えたら、それは事前登録ではない。
> **変更するなら、変更したこと自体を追記して残す。過去の記述は消さない。**

---

## 0. なぜ事前登録するのか

`src/prior.py` の採用規則は「**他者による再現の t が 3.0 以上**」である。
外部データ（論文・臨床試験・政府調達）には **OSAP に対応が無い。**
再現証拠が無いので、この規則では採用できない。

かといって「測ってから良かったものを採る」のは、
このプロジェクトが繰り返し避けてきた**選択**そのものである。

    独立観測は 58個（90日）あるいは 21個（250日）しかない。
    そこに新しいパラメータを何本も当てれば、**必ず何かが光る。**

**唯一正しいやり方は、測る前に予測を書き留めることである。**
外れたら外れたと記録する。**それが証拠になる。**

そして**再現 t が無いことは弱さの証拠ではない**（catalog §1.9.8）。
むしろ **OSAP に無い＝他人が研究していない＝混雑していない**ので、
263AT の優位性はこちら側にあるはずである。
公表数値だけのシステムは**実測で S&P500 に年5pp 負けた**（docs/05 §4.7）。

## 1. 測るもの（定義を先に固定する）

すべて `data/extern/{ticker}.json` から作る。**時点 t で既知のものだけ。**

| ID | 名前 | 定義 | 出所 |
|---|---|---|---|
| **X01** | 論文数の水準 | `ln(1 + 累計論文数)` | OpenAlex |
| **X02** | 論文数の伸び | `累計(t) / 累計(t−3年) − 1` | OpenAlex |
| **X03** | 研究強度 | `年間論文数 / 売上（百万ドル）` | OpenAlex + DERA |
| **X04** | 臨床試験の登録数 | `ln(1 + 登録済み試験数)` | ClinicalTrials |
| **X05** | 後期試験の比率 | `第3相 / 全試験` | ClinicalTrials |
| **X06** | 初期試験の数 | `ln(1 + 第1相の数)` | ClinicalTrials |

**業種内で順位→正規分布に変換する**（他のパラメータと同じ扱い）。
臨床試験系は**医薬・バイオの業種内でのみ**測る
— 半導体企業の試験数を製薬企業と比べても意味がない。

## 2. 予測（**これが事前登録の本体**）

### X01 論文数の水準 → **符号なし（効かないと予測する）**

累計論文数は**企業規模の代理変数**にすぎない。
Pfizer が 31,884 本、Moderna が 47 本なのは、
研究の質ではなく**設立年と規模**を反映している。

業種内で正規化した後は、**サイズ効果以上のものは残らない**と予測する。
→ **重みがゼロになる**、あるいは A03/A04（バリュー）と相関して消える。

**これは「効くはず」ではなく「効かないはず」という予測である。**
効かないことを予測して当てるのも、予測が当たったことに変わりはない。

### X02 論文数の伸び → **+**

研究発表の増加は、**製品化の数年前に起きる。**
決算数値（売上・利益）に現れるより早い。

市場が非財務情報に**注意を払いきれない**（limited attention）なら、
この情報は株価に織り込まれていない。

**反論も記録しておく。** 研究は費用であり、
短期の利益を圧迫する。市場が既に織り込んでいれば優位はない。
また R&D 費用そのものは先行研究で符号が安定していない。

→ **弱い +** を予測する。強くはないだろう。

### X03 研究強度（論文/売上） → **+**

売上に対して研究発表が多い＝**売上より先に投資している。**
X02 と重なるが、こちらは水準で見る。

**反論。** 売上が小さいだけの企業も高く出る。
バリュー系（A04 = S/P）と逆向きに相関する可能性がある。

→ **弱い +**。X02 より弱いと予測する。

### X04 臨床試験の登録数 → **裾に対して +、平均に対しては符号なし**

**これが本命である。**

臨床試験1本1本が**独立した当たりくじ**である。
本数が多いほど、**どれか1つが当たる確率が上がる。**
Bessembinder の「上位4%が全ての富を生む」構造と、
バイオテックの試験の構造は**同じ形をしている。**

しかし**平均リターンには効かないと予測する。**
試験は費用であり、大半は失敗する。期待値は本数に比例しない。

→ **「10倍以上になる確率」には +、平均リターンには符号なし。**

**この2つを分けて予測しているのが、この事前登録の核心である。**
片方だけ当たっても、それは半分の成功として記録する。

### X05 後期試験の比率（第3相/全試験） → **平均に +、裾には −**

第3相は承認に近い。**確度は高いが、伸びしろは小さい。**
既に価格に織り込まれている度合いも高い。

→ **平均リターンには弱い +、10倍株の確率には −**（X04 と逆向き）。

### X06 初期試験の数（第1相） → **裾に +**

第1相は失敗率が高いが、**当たったときの倍率が大きい。**
X04 の中でも、特に裾に効く部分だと予測する。

→ **X04 より裾への効きが強い**と予測する。

## 3. 測り方（**これも先に決める**）

1. **一度だけ測る。** 閾値や窓を変えて測り直さない
2. 評価は2つ。**(a) 上位N銘柄の平均リターン**、**(b) 5年で10倍になった割合**
3. 既存24本と**一緒に**縮小推定に入れ、重みがゼロでないかを見る
4. 単独でも見る（既存と相関して消えるのか、そもそも効かないのか）
5. **生存者バイアスの警告を必ず併記する**（外部データでも消えない）

**判定の基準を先に書く。**

| 結果 | 判定 |
|---|---|
| 予測した符号で、独立 t > 3.0 | **採用**（`prior.py` に追加） |
| 予測した符号で、独立 t が 2.0〜3.0 | **保留。前向き記録に回す** |
| 予測した符号だが t < 2.0 | **不採用。ただし予測は当たったと記録** |
| **予測と逆の符号** | **不採用。予測が外れたと記録し、理由を考える** |
| 予測どおり効かなかった（X01） | **予測が当たったと記録** |

**t > 3.0 を下げない。** X04 が本命だからといって甘くしない。

## 4. 予想される失敗

書いておかないと、後から「そういうつもりだった」と言えてしまう。

- **照合の失敗が最大のリスク。** `moderna` が一般語だった件のように、
  そもそも別の会社を数えている可能性がある。
  → **論文が取れた銘柄の割合**を必ず報告する。低ければ結論を出さない
- **業種の偏り。** 臨床試験は医薬・バイオにしか無い。
  → その業種内でしか測らない。全体で測ると業種ダミーになる
- **生存者バイアスはここでも効く。** 廃止銘柄は最初から入らない
- **X02 の3年窓は恣意的である。** 1年でも5年でもよかった。
  **3年に決めた理由は「決算に現れるまでの時間」という見立てだけ**で、
  データからは決めていない。**測ってから窓を変えない。**

## 6. 測定結果（2026-08-24、**一度だけ測った**）

上の §2 を書いた後、`tools/measure_prereg.py` で一度だけ測った。
**予測はほぼ全面的に外れた。**

| ID | 観測 | 上位20% | 下位20% | 差 | 10倍+の差 | 予測 | **判定** |
|---|---|---|---|---|---|---|---|
| X01 | 297 | 2.38 | 0.71 | **+1.67** | +0.00pp | 効かない | **外れ（平均に強く効いた）** |
| X02 | 296 | 1.64 | 1.60 | +0.05 | +0.00pp | 弱い + | **外れ（ほぼ無）** |
| X03 | 203 | 1.26 | 1.54 | **−0.28** | +2.50pp | 弱い + | **外れ（符号が逆）** |
| **X04** | 4,306 | 1.57 | 1.02 | **+0.55** | **−0.12pp** | 裾に+、平均は無 | **両方外れ（真逆）** |
| X05 | 3,602 | 1.35 | 0.87 | +0.48 | +0.83pp | 平均+、裾− | **平均は当たり、裾は外れ** |
| X06 | 4,306 | 1.43 | 0.99 | +0.43 | −0.12pp | 裾に+ | **外れ** |

**6本中、当たったのは X05 の平均への効きだけ。**

### 本命（X04）が真逆だった理由

事前登録にはこう書いた。

> 臨床試験1本1本が**独立した当たりくじ**である。本数が多いほど、
> どれか1つが当たる確率が上がる。
> **しかし大半は失敗するので、期待値は本数に比例しない。**

**両方の前提が間違っていた。** 実際に起きていたのは、おそらくこうである。

- **試験を多く登録できる企業は、そもそも資金力と実績がある。**
  本数は「当たりくじの枚数」ではなく**企業の体力の代理**だった。
  だから平均に効く。
- **10倍株は、試験1本しか持たない小さな企業から出る。**
  試験が多い企業は既に大きく、10倍になる余地がない。

X01 も同じ構造である。「規模の代理だから効かない」と予測したが、
**規模の代理であることは正しく、その規模が効いた。**
**論理は合っていて、結論だけ逆だった。**

### 都合よく読み替えないこと

「X01 と X04 が平均に効くなら採用すればよい」と考えたくなる。
**それは事前登録を破ることである。** §3 に書いた基準に従う。

| | 判定 |
|---|---|
| X01・X02・X03・X04・X06 | **不採用** |
| X05（平均への効き） | 予測どおりだが**独立 t を測っていない**ので保留 |

**X01 と X04 の「平均への効き」は後から見つけた関係である。**
事前に予測していない方向で出た数字を採用すれば、
それは選択であって検証ではない。
採用したいなら、**新しい仮説として登録し直し、別のデータで測る。**

### 測定自体の限界（§4 で予想した通り）

- **観測が重なっている**（19時点 × 5年後）。独立観測は 3〜4個程度。
  **t は計算していない** — 計算しても意味を持たないから
- **X01-X03 の観測は 200-300 しかない。** OpenAlex のレート制限で
  論文データが 21銘柄しか取れなかった（§4 で「照合の失敗が最大のリスク」
  と書いたが、実際に起きたのは**レート制限**だった）。
  **この3本は、そもそも結論を出せる状態ではない**
- 生存者バイアスは消えていない

### 方法としては成功した

**数字としては1本も採用できなかった。しかし方法は機能した。**

事前登録がなければ、「X01 と X04 は平均に効く」と報告していたはずである。
**予測を先に書いていたから、それが後知恵だと分かった。**

そして**外れた理由が具体的に分かった。**
「試験数＝当たりくじの枚数」ではなく「試験数＝企業の体力」だった、
という構造の誤りである。**これは次の仮説の材料になる。**

### 次に事前登録するなら

外れ方から示唆されるのは、**「規模で割る」**必要があるということ。

    試験数そのもの      → 企業の体力の代理（平均に効く）
    試験数 / 時価総額   → **1単位の企業価値あたりの当たりくじの枚数**

これは**新しい仮説**なので、**新しい事前登録として書き、別の期間で測る。**
今のデータで測れば、それは今の結果を見て作った仮説になる。
