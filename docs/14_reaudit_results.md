## 3. 予測が外れたところ — 先に書く

### 3.1 R-3（新パネル）は僅差で外れた

「−6〜−2pp」と書いて実際は **−6.45pp。** 0.45pp の超過。
**外れの方向が重要である** — 予測より**大きく**下がった。
つまり **mcap のルックアヘッドは、私が見積もったより強く効いていた。**

### 3.2 R-5 は「指標の設計」を誤った

登録した基準は「**コスト（元本比）が50%以上減る**」だった。実際は 201.2%/239.5% で、
元本比では **増えている。** 基準に照らせば不採用になる。

**しかし基準そのものが壊れていた。**
元本比のコストは**資産が増えるほど自動的に増える。** L5 は最終資産が L4 の 2.4倍なので、
**成功したことが「コスト増」として表示される。**

平均評価額に対する年率で測り直すと:

    L4 **8.14%/年** → L5 **3.94%/年**（**−51.6%**）

**機構の主張（入替チャーンがコストの主因）は的中している。**
CAGR 基準（+1.5pp以上の回復）も **+7.23pp で的中。**

→ **採用する。ただし「登録した指標では不採用だった」ことをここに残す。**
**測る前に決めた基準を、結果を見てから言い換えるのは事前登録の破壊である。**
今回は「同じ現象を別の物差しで測り直した」が、**物差しを選び直せる時点で
事前登録の力は弱まっている。** 次回からコストは**平均評価額比**で登録する。

### 3.3 R-7（投資上限0.95）は外れた

「1年窓の悪化 ≤3pp」に対し実際は **3.3pp**、そして **5年窓の無敗（0/105 → 1/105）が壊れた。**
CAGR は **+26.01% で全条件中の最高**だが、**採用しない。**

### 3.4 R-9（売りルール）は的中した

| 条件 | CAGR | 日次DD | 発動 |
|---|---|---|---|
| **なし** | **+24.06%** | −40.0% | 0 |
| 損切り −30% | +23.00% | **−35.5%** | 414 |
| 損切り −15% | +18.12% | −35.9% | 1,040 |
| トレーリング −25% | +13.96% | **−33.2%** | 1,406 |

**「なし」が CAGR で最良。** 登録した規則（CAGR と DD の両方で勝てば採用）に照らして
**売りルールは入れない。**

ただし**損切り −30% は「CAGR 1.06pp で 日次DD 4.5pp を買う」取引**である。
これは成績の問題ではなく**リスク許容度の問題**なので、
**私が決めることではない。§6 のダイヤルとして残す。**

**この再測定をもって売りの層は凍結する。** 以後このパネルで再探索しない（監査 STAT-3）。

### なぜ最小1.5%（56銘柄）を選んだか — **CAGR が高いからではない**

§4.7 の測定: **10倍株を50%の確率で1本引くには約53銘柄要る。**
2%床では 27〜45銘柄で**この閾値に届かない。** 1.5%床が**閾値に到達する最小の床**である。
1.25%（69銘柄）は閾値を超えており、**それ以上は薄めるだけ**（実測でも +19.47% と低下）。

**この理由づけは in-sample の CAGR 順位に依存しない**（組合せの議論）。
ただし**53という数値自体が生存者バイアスで甘い**ので（監査 STAT-5）、
**「閾値に最も近い床を選ぶ」以上のことは主張しない。**

## 5. この数字を信じてはいけない理由

**上振れ交絡は3つある**（監査 STAT-6 により1つ増えた）。

1. **生存者バイアス** — 2012年の残存率 32.6%。廃止銘柄は最初から入らない
2. **カタログのルックアヘッド** — パラメータの選定と符号は2024年までの OSAP を見て決めた
3. **同一パネル上の構造選択（新規）** — 売りルール・保有期間・入替方式・銘柄数を
   **すべて同じ2012-2026で選んだ。** 事前登録は多重性を減らすが**消さない**

そして統計の実体は:

- **3年窓 1/129 の独立本数は約4.5本。** 全勝でも「真のマイナス確率 ≤49%（95%CL）」までしか言えない
- **λ は格子上端に張り付き、実効本数は 4.8/31。** 重み学習層は実質不活性で、
  **+24.06% を「学習した重みの成果」と読んではいけない**
- **設計データ外（2025年以降）の擬似OOSは 1.5年しかない**:
  最終構成 +18.53%/年、SPY配当込み +17.94%/年、ランダム対照 −10.37%/年。
  **独立観測は約1.4個。方向以上のことは言えない**

### ランダム対照との差（**新しく測れるようになったもの**）

同じゲート・同じサイジング・同じコストで、**スコアだけを乱数に置き換えた**:

    最終構成 **+24.06%** / ランダム **−8.66%**（最終資産 57.5M 対 0.9M）

**差は +32.7pp/年。** ただしこれも in-sample であり、
**この差の大部分は「等加重の乱数選択が小型株の下位を大量に掴む」ことでも説明できる。**
対照が示すのは「ゲートとサイジングだけでは勝てない」ことであって、
**スコアに +32.7pp の力があることではない。**
